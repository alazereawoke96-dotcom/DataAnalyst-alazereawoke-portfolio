## Publish with GitHub Pages
1. Create a **public** repository named `alazereawoke96-dotcom.github.io`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Your site will be available at: https://alazereawoke96-dotcom.github.io

## Customize
Edit the text in `index.html` and the colors near the top of `style.css` under `:root`.
